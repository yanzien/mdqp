# 📋 mdqp 使用帮助

## 这是什么？

**mdqp**（Markdown quickly paste）是一个 Markdown 云剪贴板：**粘上就走，拿链接就分享**。
你写的 Markdown 会被保存到一个短链，任何人打开链接即可查看，支持评论、@提及与一键分享。

> 免登录也能用（游客），登录后额度更多、只有你能改自己的内容。

## 快速上手

1. 点左上角「**＋ 新建**」或首页按钮
2. 把 Markdown 粘进左侧编辑器（右侧**实时预览**、顶部**实时等效字数**统计）
3. 选好可见性（公开 / 私密）、是否加密、是否过期
4. 点「**发布**」，得到一个短链；分享给谁，谁就能看
5. 在剪贴板详情页可**评论**、**@站内好友**、**复制链接 / 二维码**

## 登录方式

mdqp 提供两条登录通道，任选其一，进入的是同一个账号体系。

### 1. 第三方登录（cpoauth）

点「第三方登录」按钮一键授权即可，无需单独注册密码。洛谷、AtCoder、Codeforces、GitHub 等关联账号会随授权自动同步到你的个人主页。

### 2. 账号密码登录（推荐每位用户都设置）

- **注册**：登录弹窗切到「注册」页，填用户名与密码。用户名 **2–20 个字符**，密码 **6–128 位**。
- **登录**：填用户名 + 密码即可，会话保持 **7 天**。
- **密码安全**：密码以**加盐 SHA-256** 存储，服务端不保存明文，也无法找回——请务必自己记牢。
- **登录保护**：密码最多 **128 位**（更长的输入会在计算前直接拒绝）；连续输错会被临时锁定，**15 分钟**内同一账号失败 8 次或同一网络失败 10 次即暂停尝试，稍后自动恢复。用户名不区分大小写重复注册。
- **用邮箱登录**：如果你已绑定 cpoauth，第三方会回传你的邮箱，之后**直接用该邮箱 + 密码**也能登录本站（邮箱来自 cpoauth，无需单独绑定）。

> **为什么要设密码？** 第三方登录服务是外部依赖，万一它宕机，没有密码就完全进不去自己的账号。设了密码等于给自己留一把备用钥匙，两种登录方式可以同时用、互不冲突。

### 老用户补设密码

如果你之前一直用第三方登录，有两种方式补设密码：

1. **跟随引导条**：登录后，若检测到你的账号还没有密码，页面顶部会自动出现一条提示，点「立即设置」即可。
2. **手动设置**：进入「**我的**」页面，点右上角齿轮 ⚙️ 打开设置弹窗，切到「**账号与安全**」页点「设置密码」。

设置弹窗需要**输入两次**密码确认，成功后即可用「用户名 + 密码」登录。若暂时不想设置，可关掉引导条，**7 天内**不会再弹出。

### 第三方服务宕机时

登录弹窗会自动探测第三方登录服务是否可达。探测失败时，第三方登录按钮会自动隐藏，并弹出提示引导你用账号密码登录——**不会把你卡在登录页**。

### 首次登录会问「你是怎么知道 mdqp 的？」

这是一次性来源统计（用于改进产品，纯匿名聚合，不与具体内容关联）。可选：线下分享 / 社交平台分享 / OJ 分享 / 其他分享 / 随便点到 / 看到广告 / 搜索引擎搜到 / 不方便说；选「其他分享」等可补充具体平台。

- **已填写或选「不方便说」后不再提醒**；
- 直接关掉弹窗：本次会话不再问；若连续多次跳过（≥3 次），则彻底不再打扰；
- 随时可改：在「我的 → 设置 → 账号与安全」里重新选择来源即可。
- 你的**注册时间**会显示在个人主页（「加入于 YYYY-MM-DD」），这是账号创建时自动记录的，不可修改。

## 跨站账号互通（oiwb）

mdqp 与 OI 训练台 **oiwb** 共用同一套账号：在 mdqp 登录后，可以从 mdqp 一键跳到 oiwb 并**自动登录**，不用再输密码。

- **怎么跳**：登录后，点左侧边栏「🚀 去 oiwb」即可。mdqp 会签一张 5 分钟一次性短票，自动带到 oiwb 换成登录态——整个过程你无感知。
- **反向带预填**：在 oiwb 里点「存到 mdqp」类按钮，会带好标题/标签跳到 mdqp 的「新建剪贴板」页（形如 `/new?title=...&tags=...&back=oiwb`），发完还能一键「↩ 返回 oiwb」。
- **安全**：短票一次性 + 5 分钟过期，跳错地址也不会泄露账号；mdqp 不可达时 oiwb 仍完全本地可用。

> 注：oiwb 需部署在 `oiwb.pages.dev` 才能使用该联动；地址由站长在配置里调整。

## 游客 vs 登录

|  | 游客 | 登录用户 |
|---|---|---|
| 创建 | ✅ 可以 | ✅ 可以 |
| 修改 / 删除 | 仅自己的 + 协作板 | 自己的随时改 |
| 日限额 | — | **5 个 / 天**（信任等级更高可提升，见下方权益矩阵） |
| 月限额 | — | **50 个 / 月** |
| 周限额 | **5 个 / 周** | — |
| 单篇字数 | 按**信任等级**分级（见下方「字数分级」）：L0/L1 **1500**、L2 **5000**、L3/VIP/管理员**不限**（硬顶 20000 等效字） | 同左 |

- **游客剪贴板**默认标记为「**任何人可编辑/删除**」的协作板，换浏览器或清缓存会失去管理权。重要内容请**登录**后再发布。
- **字数分级（v4.6 起）**：按身份自动分级——L0/L1 登录 1500 字、L2 活跃 5000 字、L3 核心 / 有效 VIP / 管理员不限（服务端硬顶 20000 等效字防滥用）。`我的` 页顶部实时显示「字数 N / 上限」，写超会自动拦截。

## 编辑器增强

- **实时预览**：左侧写、右侧立刻渲染。
- **等效字数**：顶部实时显示 `当前/上限`，超限会变红提示（中文 1 字 = 1，英文/数字/标点 = 0.5，向上取整）。
- **工具栏**：标题、加粗、斜体、删除线、代码、链接、图片、引用、列表、表格、分割线，一键插入。
- **🔧 一键修复**：点工具栏的 🔧 打开修复弹窗，自动修正常见问题——代码围栏 / 数学公式 / 删除线的配对错误、行尾多余空白，并校验 KaTeX 数学公式语法。修完可直接回填编辑器或复制走。
- **@提及**：在评论或内容里输入 `@` 可自动补全站内用户。
- **目录（TOC）**：长文可展开大纲。

## 账号关联与设置

### 关联 cpoauth 账号

如果你先用**账号密码**注册登录，后来又想同步竞赛账号，无需新建号：

- 进入「**我的**」→ 齿轮 ⚙️ →「**账号与安全**」页，点「**绑定 cpoauth**」；
- 完成第三方授权后，回调会把竞赛账号（`sub`）**写回你当前这个密码账号**，两条通道合一，不会凭空多出一个孤儿账号。

反过来，第三方登录用户也可在「账号与安全」里补设密码，详见上文「老用户补设密码」。

### 设置弹窗

「我的」和个人主页的齿轮 ⚙️ 都打开同一个设置弹窗，分两个页签：

- **通用**：修改个性签名、个人简介（bio，500 字内）、界面主题（浅色 / 深色 / 跟随系统）。
- **账号与安全**：查看密码是否已设置、cpoauth 是否已绑定、绑定邮箱、信任等级，并可在此登出、设置密码、绑定 cpoauth。

### 战绩概览

「我的」和个人主页新增 🏆 **战绩概览** 区：

- 嵌入 cpoauth 的**竞赛名片**（`card.svg`），随主题明暗自动切换；仅当你已关联竞赛账号时显示，未关联者展示说明文字。
- ⚠️ **详细战绩暂无法使用**：因上游调整，各平台 rating / 最高 rating / 场次 / 排名等详细数据暂不可获取，战绩区会标注「详细战绩暂无法使用，等待更新」。竞赛名片不受影响，上游恢复后详细战绩将自动可用。

### 信任等级与成就徽章

#### 信任等级判定规则

信任等级由系统**自动实时计算**，无需申请，显示在「我的」、个人主页资料卡中。当前等级取「满足条件中的最高档」。

**v4.5.2 起改为「维持制」**：高等级不是拿到就永久保留，必须**持续达标**，一段时间不活跃会自动回落。

| 等级 | 称号 | 晋升条件 |
|---|---|---|
| **L0** | 🌱 新手上路 | 注册后的默认等级，无需任何条件 |
| **L1** | 🔵 常驻用户 | 创建过 **≥ 1 个**剪贴板，**或**注册满 **1 天**（满足其一即可） |
| **L2** | 🟣 活跃用户 | 近 **14 天**新建 **≥ 5 个**剪贴板 **且** 已成功邀请 **≥ 1 位**好友（两条都要满足） |
| **L3** | 🔴 核心用户 | 满足 L2 的**全部**条件 **且** 近 **5 天**新建 **≥ 1 个**剪贴板 **且** 累计邀请 **≥ 3 位**好友；站点管理员 / 开发者恒为 L3 |

细则说明：

- **窗口怎么算**：`近 14 天` / `近 5 天` 指的是**从当前时刻往前推**的滚动窗口，按剪贴板的创建时间统计。**被删除的剪贴板不再计入**，所以删太多板会导致等级回落。
- **只统计登录账号名下**的剪贴板，游客剪贴板不计入；邀请数只统计**成功注册并绑定**的好友。
- **提升**会通过 🔔 通知推送一次「🎉 信用等级提升」，同一等级不会重复提醒。
- **回落不发通知**：不达标时资料卡等级会实时下调，但不会推送降级通知，避免打扰。
- 想看还差多少：「我的」页有 **🛡 信任等级** 区块，设置 → 账号与安全里也有，会显示「近 14 天 X 个 · 近 5 天 Y 个 · 已邀请 Z 人」以及升到下一级还差的具体条件。

旧的「默认 300 字上限」对写算法题解 / 完整文档来说太苛刻。v4.6 起按身份自动分级：

### 通知 🔔

登录后，导航栏右上角会出现 **🔔 铃铛**，自动归集四类通知，按类别彩色标签区分：

- 🎉 **信用等级**：你的信任等级提升时通知（如晋升「核心用户」）；
- ⏳ **剪贴板到期**：你设置了有效期的剪贴板，在到期前 24 小时（或已过期）提醒你及时查看或延长；
- 👀 **剪贴板被访问**：你的剪贴板首次被外部访客打开时通知；
- 🛡 **后台管理**：管理员对你账号做出变更（设/撤管理员、调整剪贴板限额、开/关 VIP、更新功能开关或管理权限）时通知你。

## 管理后台 🛡

仅管理员 / 开发者可见（侧边栏 🛡）。后台 tab 会**按权限自动出现**：没有某项权限，对应 tab 和按钮直接不显示；服务端也会二次校验，前端绕过无效。

### 后台包含哪些 tab

- **👥 用户**：设 / 撤 VIP、功能开关（复选框）、升 / 撤管理员（勾选权限）、删除账号、搜索用户
- **📋 全部剪贴板**：查看 / 删除任意剪贴板、搜索（**按权限区分公开 / 私有**：没 `view_private_clips` 的管理员，列表里根本不会出现私有剪贴板）
- **📄 站点页面**：编辑帮助 / 关于页（Markdown）
- **🌐 站点**：全站站点治理——查看列表、封禁 / 解封 / 删除（三档权限，见下）
- **📊 额度**：查看每日 D1 / KV 额度进度与自动刹车状态；**修改额度上限需 `manage_quota` 权限**
- **💬 聊天管理**：群列表与一键删群
- **🛡 IP 治理**：查看 / 封禁 / 解封 IP 与网段（需 `manage_ip` 权限，详见下）
- **📢 公告**：发布 / 删除
- **🎁 邀请**：查看邀请记录
- **📊 数据看板**：全站统计
- **⚙️ 设置**：修改站点配置（限额、VIP 联系方式等）
- **💻 代码**（需 `view_code`）：在线浏览站点源码、查看审批队列；**编辑并提交改动**需 `edit_code`（或开发者）。仅 `view_code` 时显示「👁 只读」；同时有 `edit_code` 或开发者才显示「✏️ 可编辑」

### 管理员权限颜色梯度

按掌握权限多少从低到高：🔵 蓝 → 🟢 绿 → 🟠 橙 → 🔴 红 → 🟣 紫（最高）；**开发者也是紫色**。

### 细粒度权限体系（27 项）

由拥有「管理其他管理员（`manage_admins`）」权限的人逐项授予。授予高阶权限会自动带上其依赖的低阶（蕴含闭包）。共 6 组：

- 👥 **用户管理**：封禁 / 解封用户、删除账号、设置剪贴板限额、修改功能开关、授予 / 撤销 VIP、管理其他管理员
- 📚 **剪贴板管理**：公开 / 私有 × 查看 / 编辑 / 删除，共 6 项。**私有剪贴板是最高敏感数据**，必须单独授予 `*_private_clips`；勾「删除」会自动带上「编辑 / 查看」
- 🌐 **网站治理**（递进：删除 ⊃ 封禁 ⊃ 查看）：`view_sites`（只看列表）⊂ `ban_sites`（+ 封禁 / 解封）⊂ `delete_sites`（+ 删除）。勾高阶自动带低阶，**不能只给「删除」不给「查看」**
- 🛠 **站点与内容**：管理评论、编辑站点页面、发布公告、处理工单、管理邀请、站点设置
- 💻 **代码管理**：查看源码（只读）、编辑并提交代码
- 🛡 **治理与额度**（站长可逐项授予的开关）：
  - `manage_ip` —— **IP 治理**：查看 / 封禁 / 解封 IP 与网段
  - `manage_sites` —— **站点治理统一开关**：勾选即同时拥有 `view_sites` / `ban_sites` / `delete_sites`（查看 + 封禁 + 删除网站）
  - `manage_quota` —— **配额治理**：修改 D1 / KV 每日额度上限
  - `manage_snapshot_quota` —— **快照配额治理**：设置用户快照配额（单人 / 批量）

### 🛡 IP 治理与「自锁保护」

IP 治理用于按 IP 聚合注册账号、批量封禁 / 解封。被封 IP 无法注册且访问接口直接拒绝。

**⚠️ 自锁保护（v4.32.1 起）**：系统**禁止把开发者（站长）或你本人当前使用的 IP / 网段拉黑**——即使有 `manage_ip` 权限，尝试封禁以下目标也会被拒绝并返回明确提示：

- 你本次操作所用的公网 IP；
- 任意**开发者（站长）账号**曾在 `user_ips` 中记录过的 IP；
- 覆盖上述任一 IP 的**网段（CIDR）**。

这是为了防止误操作把运维自己锁在门外。若确需封禁某个与开发者同网段的范围，请先由开发者更换出口 IP 或走其它合规流程。

## 常见问题

**Q：登录成功却显示未登录？**
A：通常是浏览器缓存了旧的前端。请**硬刷新**（Ctrl+Shift+R / Cmd+Shift+R）再试；仍不行清掉本站 Cookie 重新登录。

**Q：页面一片空白，只剩侧边导航和底部按钮？**
A：这是**浏览器内核太老**（如 IE、旧版 Edge）导致的，不是网络问题——本站用了 CSS 变量与 ES6 语法，老内核解析即失败。正常情况下现在会直接弹出「浏览器内核过旧」的提示页并给出下载入口（Firefox 官方 / 腾讯软件中心镜像）；如果连提示都没出来，请手动换用 Chrome、Edge（新版）或 Firefox 打开。

**Q：首页能打开，但列表一片空白，或顶部提示「页面结构加载不完整」？**
A：多半是**网络代理返回了旧缓存 / 被截断的页面**（机房网络常见），不是站点坏了。按 **Ctrl + F5** 强制刷新（或点提示条里的「强制刷新」）通常立刻恢复。现在这种情况下页面会有黄色提示条引导你，不会再静默空白。

**Q：第三方登录按钮不见了？**
A：说明第三方登录服务暂时不可达（弹窗打开时会自动探测）。请直接使用**账号密码登录**；如果你之前只用过第三方登录且没设过密码，需要等第三方服务恢复后再补设——所以建议尽早设一个。

**Q：忘记密码了怎么办？**
A：密码是加盐哈希存储的，**服务端无法找回也无法重置**。请使用第三方登录进入账号，然后在「我的 → 🔐 账号与安全」里重设一个新密码。

**Q：编辑后保存了但内容没变？**
A：保存会实时写库，若遇到网络异常会提示失败。请确保保存时网络正常，保存后留意「已保存」提示。

**Q：提示超过字数上限？**
A：单篇字数按**信任等级**分级：L0/L1 **1500**、L2 **5000**、L3 / 有效 VIP / 管理员**不限**（硬顶 20000 等效字；中文 1 字算 1，英文/数字/标点算 0.5）。提升信任等级或开通 VIP 可解锁更高额度，长文也可拆成多篇。

**Q：国内打开慢/打不开？**
A：站点由 Cloudflare 免费版托管，国内直连可能偏慢或不稳。可挂 VPN 访问，或等待后续国内镜像。

**Q：游客内容被别人改了？**
A：游客剪贴板默认是协作板（任何人可改/删）。重要内容请**登录**后再发布。

## 🌐 网站托管（qsites）

在「🌐 网站」里可以创建并托管你自己的静态网站（HTML/CSS/JS/图片），发布后通过独立地址 `https://qsites.pages.dev/<你的标识>` 访问。

**Q：怎么建站？**
A：进入「🌐 网站」→「＋ 新建」，填标识（小写字母/数字/连字符，2–31 位，不能是保留字）和标题。建好后有两种上传方式：①「📁 选择整个文件夹上传」选本地站点文件夹（自动去掉最外层目录名）；②「⚙️ 或粘贴一段 HTML 快速生成首页」，适合单页。

**Q：文件怎么改？**
A：文本类文件（html / css / js / json / md / svg / txt 等）在文件列表点「✎ 编辑」即可在线修改并保存；图片等二进制文件需重新上传同路径覆盖。

**Q：访问地址是什么？**
A：发布后访问 `https://qsites.pages.dev/<标识>`。注意用户站点和 mdqp 主站**不同源**，用户站里的 JS 无法读取主站数据，这是安全隔离设计。

**Q：配额有多少？**
A：普通用户 3 个站 / 每站 5MB / 单文件 1MB / 200 文件；VIP 10 个站 / 20MB / 5MB / 500 文件。文件更新后数十秒生效（KV 最终一致）。

**Q：删除失败 / 打不开？**
A：如果改完打不开，等几十秒刷新就好（KV 有短暂延迟）。违规站点会被管理员封禁（显示 403）。

**Q：发现有站点内容违规，怎么举报？**
A：在「🌐 网站」页点右上角「⚠ 举报站点」，填写对方网址标识（**也可以直接粘贴 `https://qsites.pages.dev/xxx` 链接，会自动提取标识**）、选择原因、补充情况后提交。举报会生成一条「内容举报」工单并关联该站点，管理员可在工单里直接封禁或删除站点；同一站点你只需举报一次（未处理前重复提交会自动合并）。进度可在「工单」里查看。

**Q：我的站点被封禁了怎么办？**
A：被封禁后访问会返回 403，编辑器里会显示红色横幅说明封禁原因，且上传 / 发布按钮不可用。如果认为误判，可以**一键申诉**，入口有三处，任选其一：

1. 访问被封禁的地址时，403 页面上直接有「📮 一键申诉」按钮；
2. 「🌐 我的网站」列表里，被封禁的站点卡片上会出现「📮 一键申诉」；
3. 进入该站点的编辑器，红色封禁横幅里也有「📮 一键申诉」。

点进去会**自动填好申诉分类和站点**，你只需写清楚申诉理由并提交。申诉会生成一条「封禁申诉」工单，管理员核实后可在工单里点「✅ 申诉成立：解除封禁站点」一键恢复，并会通知你结果。同一站点的未处理申诉只保留一条。

**Q：我主动下架了站点，别人还能访问吗？**
A：不能。下架（或还没发布过任何文件）的站点访问时会显示「该网站暂不可访问」，只有点过「🚀 发布」的站点才会对外可见。

**Q：访问别人的网站时右下角那个小按钮是什么？**
A：是一个小小的「⚠ 举报」入口，方便你在浏览时顺手举报违规站点。点 ✕ 就能关掉，关过之后这个站点不再显示它。

## 🕐 时间显示

**Q：页面上的时间是按哪个时区算的？**
A：统一按 **UTC+8（北京时间）** 显示。数据库里存的始终是标准 UTC 时间，前端渲染时自动换算，所以不受你自己电脑时区设置的影响 —— 把系统时区改成别的，网站上看到的时间仍然是北京时间。

**Q：为什么之前看到的时间不对？**
A：早期版本有几处直接把数据库里的 UTC 原始值显示出来了（聊天消息时间、工单「创建于」、公告时间等），会比实际早 8 小时。v4.19.2 起已全部修正。
