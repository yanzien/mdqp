# 📋 mdqp 使用帮助

## 这是什么？

**mdqp**（Markdown quickly paste）是一个 Markdown 云剪贴板：**粘上就走，拿链接就分享**。
你写的 Markdown 会被保存到一个短链，任何人打开链接即可查看，支持评论、@提及与一键分享。

> 免登录也能用（游客），登录后额度更多、只有你能改自己的内容。

---

## 快速上手

1. 点左上角「**＋ 新建**」或首页按钮
2. 把 Markdown 粘进左侧编辑器（右侧**实时预览**、顶部**实时等效字数**统计）
3. 选好可见性（公开 / 私密）、是否加密、是否过期
4. 点「**发布**」，得到一个短链；分享给谁，谁就能看
5. 在剪贴板详情页可**评论**、**@站内好友**、**复制链接 / 二维码**

## 登录方式

mdqp 提供两条登录通道，任选其一，进入的是同一个账号体系。

### 1. 第三方登录（cpoauth）

点「第三方登录」按钮一键授权即可，无需单独注册密码。洛谷、AtCoder、Codeforces、GitHub 等关联账号会随授权自动同步到你的个人主页。

### 2. 账号密码登录（推荐每位用户都设置）

- **注册**：登录弹窗切到「注册」页，填用户名与密码。用户名 **2–20 个字符**，密码 **6–128 位**。
- **登录**：填用户名 + 密码即可，会话保持 **7 天**。
- **密码安全**：密码以**加盐 SHA-256** 存储，服务端不保存明文，也无法找回——请务必自己记牢。
- **登录保护**：密码最多 **128 位**（更长的输入会在计算前直接拒绝）；连续输错会被临时锁定，**15 分钟**内同一账号失败 8 次或同一网络失败 10 次即暂停尝试，稍后自动恢复。用户名不区分大小写重复注册。
- **用邮箱登录**：如果你已绑定 cpoauth，第三方会回传你的邮箱，之后**直接用该邮箱 + 密码**也能登录本站（邮箱来自 cpoauth，无需单独绑定）。

> **为什么要设密码？** 第三方登录服务是外部依赖，万一它宕机，没有密码就完全进不去自己的账号。设了密码等于给自己留一把备用钥匙，两种登录方式可以同时用、互不冲突。

### 老用户补设密码

如果你之前一直用第三方登录，有两种方式补设密码：

1. **跟随引导条**：登录后，若检测到你的账号还没有密码，页面顶部会自动出现一条提示，点「立即设置」即可。
2. **手动设置**：进入「**我的**」页面，点右上角齿轮 ⚙️ 打开设置弹窗，切到「**账号与安全**」页点「设置密码」。

设置弹窗需要**输入两次**密码确认，成功后即可用「用户名 + 密码」登录。若暂时不想设置，可关掉引导条，**7 天内**不会再弹出。

### 第三方服务宕机时

登录弹窗会自动探测第三方登录服务是否可达。探测失败时，第三方登录按钮会自动隐藏，并弹出提示引导你用账号密码登录——**不会把你卡在登录页**。

## 游客 vs 登录

|  | 游客 | 登录用户 |
|---|---|---|
| 创建 | ✅ 可以 | ✅ 可以 |
| 修改 / 删除 | 仅自己的 + 协作板 | 自己的随时改 |
| 日限额 | — | **5 个 / 天** |
| 月限额 | — | **50 个 / 月** |
| 周限额 | **5 个 / 周** | — |
| 单篇字数 | ≤ **300** 等效字（中文算 1，英文/标点算 0.5） | ≤ **300** 等效字（VIP 不限） |

- **游客剪贴板**默认标记为「**任何人可编辑/删除**」的协作板，换浏览器或清缓存会失去管理权。重要内容请**登录**后再发布。
- 管理员与**有效 VIP** 不受字数限制。

## 编辑器增强

- **实时预览**：左侧写、右侧立刻渲染。
- **等效字数**：顶部实时显示 `当前/300`，超限会变红提示（中文 1 字 = 1，英文/数字/标点 = 0.5，向上取整）。
- **工具栏**：标题、加粗、斜体、删除线、代码、链接、图片、引用、列表、表格、分割线，一键插入。
- **🔧 一键修复**：点工具栏的 🔧 打开修复弹窗，自动修正常见问题——代码围栏 / 数学公式 / 删除线的配对错误、行尾多余空白，并校验 KaTeX 数学公式语法。修完可直接回填编辑器或复制走。
- **@提及**：在评论或内容里输入 `@` 可自动补全站内用户。
- **目录（TOC）**：长文可展开大纲。

## 账号关联与设置

### 关联 cpoauth 账号

如果你先用**账号密码**注册登录，后来又想同步竞赛账号，无需新建号：

- 进入「**我的**」→ 齿轮 ⚙️ →「**账号与安全**」页，点「**绑定 cpoauth**」；
- 完成第三方授权后，回调会把竞赛账号（`sub`）**写回你当前这个密码账号**，两条通道合一，不会凭空多出一个孤儿账号。

反过来，第三方登录用户也可在「账号与安全」里补设密码，详见上文「老用户补设密码」。

### 设置弹窗

「我的」和个人主页的齿轮 ⚙️ 都打开同一个设置弹窗，分两个页签：

- **通用**：修改个性签名、个人简介（bio，500 字内）、界面主题（浅色 / 深色 / 跟随系统）。
- **账号与安全**：查看密码是否已设置、cpoauth 是否已绑定、绑定邮箱、信任等级，并可在此登出、设置密码、绑定 cpoauth。

### 战绩概览

「我的」和个人主页新增 🏆 **战绩概览** 区：

- 嵌入 cpoauth 的**竞赛名片**（`card.svg`），随主题明暗自动切换；仅当你已关联竞赛账号时显示，未关联者展示说明文字。
- ⚠️ **详细战绩（`cp:summary`）暂无法使用**：因上游调整，各平台 rating / 最高 rating / 场次 / 排名等详细数据暂不可获取，战绩区会标注「详细战绩暂无法使用，等待更新」。竞赛名片不受影响，上游恢复后详细战绩将自动可用。

### 信任等级与成就徽章

#### 信任等级判定规则

信任等级由系统**自动实时计算**，无需申请，显示在「我的」、个人主页资料卡中。当前等级取「满足条件中的最高档」。

**v4.5.2 起改为「维持制」**：高等级不是拿到就永久保留，必须**持续达标**，一段时间不活跃会自动回落。

| 等级 | 称号 | 晋升条件 |
|---|---|---|
| **L0** | 🌱 新手上路 | 注册后的默认等级，无需任何条件 |
| **L1** | 🔵 常驻用户 | 创建过 **≥ 1 个**剪贴板，**或**注册满 **1 天**（满足其一即可） |
| **L2** | 🟣 活跃用户 | 近 **14 天**新建 **≥ 5 个**剪贴板 **且** 已成功邀请 **≥ 1 位**好友（两条都要满足） |
| **L3** | 🔴 核心用户 | 满足 L2 的**全部**条件 **且** 近 **5 天**新建 **≥ 1 个**剪贴板 **且** 累计邀请 **≥ 3 位**好友；站点管理员 / 开发者恒为 L3 |

细则说明：

- **窗口怎么算**：`近 14 天` / `近 5 天` 指的是**从当前时刻往前推**的滚动窗口，按剪贴板的创建时间统计。**被删除的剪贴板不再计入**，所以删太多板会导致等级回落。
- **只统计登录账号名下**的剪贴板，游客剪贴板不计入；邀请数只统计**成功注册并绑定**的好友。
- **提升**会通过 🔔 通知推送一次「🎉 信用等级提升」，同一等级不会重复提醒。
- **回落不发通知**：不达标时资料卡等级会实时下调，但不会推送降级通知，避免打扰。
- 想看还差多少：「我的」页有 **🛡 信任等级** 区块，设置 → 账号与安全里也有，会显示「近 14 天 X 个 · 近 5 天 Y 个 · 已邀请 Z 人」以及升到下一级还差的具体条件。

#### v4.6 权益矩阵（高等级有什么用）

信任等级 / VIP / 管理员不再只是「限制少」，而是**真的能多做事**。每个等级有 8 项权益，登录后在「我的 → 🎁 当前权益」区块里能看到你当前等级解锁了哪些。

| 权益 \ 等级 | L0 新手 | L1 常驻 | L2 活跃 | L3 核心 | VIP / 管理员 |
|---|---|---|---|---|---|
| 单篇字数 | 1500 | 1500 | 5000 | **不限** | **不限** |
| 每日新建数 | 5 | 10 | 20 | 50 | **不限** |
| 每月新建数 | 50 | 100 | 300 | 800 | **不限** |
| 标签数 / 板 | 3 | 10 | 30 | **不限** | **不限** |
| 私有剪贴板 | 50 | 200 | 1000 | **不限** | **不限** |
| 版本回退 | — | 3 | 10 | 50 | 50 |
| 自定义短链 | ❌ | ❌ | ✅ | ✅ | ✅ |
| 批量导出 CSV | ❌ | ✅ | ✅ | ✅ | ✅ |
| 成就徽章 | ❌ | ❌ | ✅ | ✅ | ✅ |

「不限」项的服务端硬封顶是 **20000 等效字 / 板**，防止滥用。

#### v4.6 字数分级（旧 300 字限制已废）

旧的「默认 300 字上限」对写算法题解 / 完整文档来说太苛刻。v4.6 起按身份自动分级：

- **游客**：1500 字 / 板（够写一段题解 + 几个代码块）
- **L0/L1 登录**：1500 字 / 板
- **L2 活跃**：5000 字 / 板
- **L3 核心 / VIP / 管理员**：不受限（封顶 20000）

「我的」顶部实时显示「字数 N / 上限」，写超会自动拦截并给出「再写多少字」提示。

#### v4.6 草稿自动保存（防丢稿神器）

编辑页打开时，自动把内容**每 500 毫秒**写一份到浏览器的 `localStorage`：

- 新建草稿 → 键 `mdqp_draft_new`
- 编辑已有板 → 键 `mdqp_draft_<短链>`

刷新页面 / 重开标签 / 误关页面后，下次进入编辑器顶部会出现**蓝条提示**「检测到未保存的草稿（3 分钟前）」，点「恢复」一键回填。点「丢弃」清理。保存成功后自动清理。关闭页面前 `beforeunload` 会二次确认。

> 草稿只存在你**当前浏览器**本地，不上传服务端，换设备 / 清理浏览器会丢。

#### v4.6 我的剪贴板 2.0

「我的」页的剪贴板列表升级为**真正的个人管理面板**（不再只是公开板的筛选）：

- **🔍 搜索框**：搜标题、内容、作者，按你的**全部**剪贴板匹配（含私有板，公开站点的搜索不会搜到）
- **4 种排序**：最近更新 / 最近创建 / 最多浏览 / 标题 A–Z
- **⭐ 只看置顶**：勾选后只列出你置顶的板
- **🏷 标签云**：从你所有板里聚合出现的标签，点击即筛选；当前激活的标签下面会高亮，再点一次清除
- **⭐ 单板置顶**：每张卡片右上角有 ⭐ 按钮，点一下置顶（再点取消），置顶的板在公开站点也会被优先展示

标签上限由你的权益等级决定：L0 3 个 / L1 10 个 / L2 30 个 / L3+ 不限。

#### v4.6.2 主页也能搜我的剪贴板

主页「公开剪贴板」标题旁新增 **「🌐 公开 / ⭐ 我的」** 范围切换（登录用户可见，游客不显示）：

- 点「⭐ 我的」后，主页列表切换为**你自己的全部剪贴板（含私有）**，顶部搜索框同步变为「搜索我的剪贴板」，支持卡片 ⭐ 置顶；
- 点「🌐 公开」恢复公开列表；游客只能看到公开列表。

#### 成就徽章

- **成就徽章**：系统派生的一组成就（已连 cpoauth / 双保险 / 已设密码 / VIP / 剪贴板达人 / 邀请达人 / 管理员），在个人主页以图标展示。与信任等级相互独立：徽章看「特征」，等级看「活跃度」。

### 通知 🔔

登录后，导航栏右上角会出现 **🔔 铃铛**，自动归集四类通知，按类别彩色标签区分：

- 🎉 **信用等级**：你的信任等级提升时通知（如晋升「核心用户」）；
- ⏳ **剪贴板到期**：你设置了有效期的剪贴板，在到期前 24 小时（或已过期）提醒你及时查看或延长；
- 👀 **剪贴板被访问**：你的剪贴板首次被外部访客打开时通知；
- 🛡 **后台管理**：管理员对你账号做出变更（设/撤管理员、调整剪贴板限额、开/关 VIP、更新功能开关或管理权限）时通知你。

点击铃铛展开面板：未读以红点角标计数；点单条可标记为已读并跳转相关页面；「全部已读」一键清空；顶部「信用 / 到期 / 访问 / 管理」可分类筛选。通知随账号保存，换设备登录同样可见。

## 意见反馈 📮

进入「**反馈**」页（侧边栏 📮），可提交两类内容：

- **Bug 反馈**：会自动附带你的浏览器环境、当前页面与最近的控制台日志，便于定位问题
- **意见反馈**：功能建议、体验吐槽

管理员可在后台审核、处理反馈。

### 出错自动提示（不用开 F12）

v4.5.2 起，页面会**自动捕获**这些异常并直接弹出提示：

- JS 脚本报错、未处理的异步（Promise）异常
- 关键资源（脚本 / 样式）加载失败
- 接口返回 **5xx** 或网络请求失败

弹窗里能看到：错误类型、发生时间、所在页面、错误信息，点「查看技术详情」还有**完整调用堆栈 + 运行环境（浏览器 / 系统 / 屏幕 / 版本）+ 最近控制台日志**，可直接「📋 复制详情」。

**隐私边界**：这些信息**只显示在你自己的屏幕上**，不会自动发送。只有当你点 **「🐞 反馈给站长」**（即同意后）才会跳转到反馈页，并自动填好环境、报错堆栈与日志，你补充「具体情况」后提交即可。同一个错误 30 秒内只弹一次，不会刷屏。

想主动上报最近一次报错：按 `Ctrl / Cmd + K` 打开命令面板，选「**上报最近一次报错**」。

## 常见问题

**Q：登录成功却显示未登录？**
A：通常是浏览器缓存了旧的前端。请**硬刷新**（Ctrl+Shift+R / Cmd+Shift+R）再试；仍不行清掉本站 Cookie 重新登录。

**Q：第三方登录按钮不见了？**
A：说明第三方登录服务暂时不可达（弹窗打开时会自动探测）。请直接使用**账号密码登录**；如果你之前只用过第三方登录且没设过密码，需要等第三方服务恢复后再补设——所以建议尽早设一个。

**Q：忘记密码了怎么办？**
A：密码是加盐哈希存储的，**服务端无法找回也无法重置**。请使用第三方登录进入账号，然后在「我的 → 🔐 登录安全」里重设一个新密码。

**Q：编辑后保存了但内容没变？**
A：保存会实时写库，若遇到网络异常会提示失败。请确保保存时网络正常，保存后留意「已保存」提示。

**Q：提示超过 300 字？**
A：单篇上限是 **300 等效字**（中文 1 字算 1，英文/数字/标点算 0.5）。开通 VIP 可豁免，或把长文拆成多篇。

**Q：国内打开慢/打不开？**
A：站点由 Cloudflare 免费版托管，国内直连可能偏慢或不稳。可挂 VPN 访问，或等待后续国内镜像。

**Q：游客内容被别人改了？**
A：游客剪贴板默认是协作板（任何人可改/删）。重要内容请**登录**后再发布。
