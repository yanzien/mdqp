# 📋 mdqp 使用帮助

## 这是什么？

**mdqp**（Markdown quickly paste）是一个 Markdown 云剪贴板：**粘上就走，拿链接就分享**。
你写的 Markdown 会被保存到一个短链，任何人打开链接即可查看，支持评论、@提及与一键分享。

> 免登录也能用（游客），登录后额度更多、仅你能改自己的内容。

---

## 快速上手

1. 点左上角「**＋ 新建**」或首页按钮
2. 把 Markdown 粘进左侧编辑器（右侧**实时预览**、顶部**实时等效字数**统计）
3. 选好可见性（公开 / 私密）、是否加密、是否过期
4. 点「**发布**」，得到一个短链；分享给谁，谁就能看
5. 在剪贴板详情页可**评论**、**@站内好友**、**复制链接 / 二维码**

---

## 游客 vs 登录

|  | 游客 | 登录用户 |
|---|---|---|
| 创建 | ✅ 可以 | ✅ 可以 |
| 修改 / 删除 | 仅自己的 + 协作板 | 自己的随时改 |
| 日限额 | — | **5 个 / 天** |
| 月限额 | — | **50 个 / 月** |
| 周限额 | **5 个 / 周** | — |
| 单篇字数 | ≤ 150 等效字（非中文算 1，英文/标点折半） | ≤ 150 等效字 |

- 游客剪贴板默认标记为「**任何人可编辑/删除**」的协作板，换浏览器/清缓存会失去管理权。
- 登录用 **cpoauth** 一键授权，无需单独注册密码。

---

## 编辑器增强

- **实时预览**：左侧写、右侧立刻渲染。
- **等效字数**：顶部实时显示 `当前/150 等效字`，超限会变红提示（中文 1 字 = 1，英文/标点 = 0.5）。
- **工具栏**：加粗、斜体、代码、链接、标题、引用、列表、表格一键插入。
- **@提及**：在评论或内容里输入 `@` 可自动补全站内用户。
- **目录**：长文可展开大纲（TOC）。

## 高级功能（默认开放项）

| 功能 | 说明 |
|---|---|
| 🔒 密码保护 | 设访问密码（SHA-256 加密，作者本人免密） |
| ⏰ 定时过期 | 到时间自动不可访问 |
| 👁 阅读次数上限 | 达到次数后自动隐藏 |
| 🤝 协作模式 | 允许任何人编辑/删除 |
| 🔑 登录可见 | 仅登录用户可查看，未登录看到登录按钮 |
| 👥 读者数限制 | 按**唯一人**算（非次数），游客按设备信息判断 |
| 💬 评论功能 | 打开后详情页可评论 |
| 🔗 自定义短链 | 用容易记的短链代替随机 ID（需权限） |

> 管理员可为每个用户**单独开关**上述功能；默认除「自定义短链、阅读次数上限」外全部开放。

## 评论与 @提及

- 支持 **Markdown**，每用户**限 50 等效字**，**必须登录**才能评论。
- 输入 `@` + 用户名可**@站内用户**，对方会看到提醒。
- 作者可在管理后台管理评论。

## 邀请系统 🎁

进入「**邀请**」页（侧边栏 🎁），生成你的**专属邀请码 + 链接**，一键复制分享。

朋友通过你的链接**首次**登录本站，你们双方各记录 1 人。累计邀请人数自动发放奖励（默认）：

| 邀请人数 | 奖励 |
|---|---|
| 1 人 | 开放**所有高级功能** |
| 3 人 | 开通 ⭐ **VIP（永久）** |
| 5 人 | 不限字数 + 剪贴板**置顶**权限 |
| 10 人 | 🎁 **开发者大礼包**（加站长微信细谈） |

被邀请者注册即获得**自定义短链**权限。管理员可在后台调整奖励规则。

## VIP ⭐

成为 VIP 享专属**金黄色标识**与更多特权。获取方式：

- 邀请 **3 位**好友自动开通
- 由有权的管理员在用户主页 / 后台直接授予
- 开通时页面会提示**加站长微信**

VIP 特权：金色 VIP 徽章、更高的可见度与专属身份标识（具体特权随版本扩展）。

## 公告 📢

首页公开剪贴板列表**顶部**会置顶显示管理员发布的公告（支持 Markdown）。普通用户只读，仅管理员可在后台发布/删除。

---

## 个人主页与个人简介

- 每个用户都有公开主页：`/u/<你的ID>`，展示头像、签名、简介、关联账号、剪贴板。
- **个人简介（bio）**：可在「我的 → 编辑个人资料」里填写（500 字内），也会在你用 cpoauth 登录时同步一次 cpoauth 的简介。
- **个性签名**：200 字内，展示在名字下方。
- 关联账号（洛谷 / AtCoder / Codeforces / GitHub 等）随 cpoauth 授权自动同步。

## 管理后台 🛡

仅管理员/开发者可见（侧边栏 🛡）。包含：

- **用户管理**：设/撤 VIP、功能开关（复选框）、升/撤管理员（勾选权限）、删除账号、搜索用户
- **全部剪贴板**：查看/删除任意剪贴板、搜索
- **站点页面**：编辑帮助/关于页（Markdown）
- **公告**：发布/删除
- **邀请**：查看邀请记录
- **设置**：修改站点配置（限额、VIP 联系方式等）

**管理员权限颜色梯度**（按掌握权限多少，从低到高）：
🔵 蓝 → 🟢 绿 → 🟠 橙 → 🔴 红 → 🟣 紫（最高）；**开发者也是紫色**。

## 常见问题

**Q：登录成功却显示未登录？**
A：通常是浏览器缓存了旧的前端。请**硬刷新**（Ctrl+Shift+R / Cmd+Shift+R）再试；仍不行清掉本站 Cookie 重新登录。

**Q：编辑后保存了但内容没变？**
A：保存会实时写库，若遇到网络异常会提示失败。请确保保存时网络正常，保存后留意「已保存」提示。

**Q：国内打开慢/打不开？**
A：站点由 Cloudflare 免费版托管，国内直连可能偏慢或不稳。可挂 VPN 访问，或等待后续国内镜像。

**Q：游客内容被别人改了？**
A：游客剪贴板默认是协作板（任何人可改/删）。重要内容请**登录**后再发布。
