# ℹ️ 关于 mdqp

**mdqp**（Markdown quickly paste）是一个**免费、免登录**的 Markdown 云剪贴板。

## 理念

粘上就走，拿链接就分享。把临时笔记、代码片段、分享内容丢到这里，生成一个短链就能发给任何人。

## 技术

- 前端：原生 HTML / CSS / JS（SPA，无构建步骤）
- 后端：Cloudflare Workers（Hono）+ D1（SQLite）
- 身份：cpoauth OAuth 2.0
- 渲染：marked + DOMPurify + highlight.js
