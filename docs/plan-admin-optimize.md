# mdqp 小规划：后台权限分离 + 管理/优化

> 范围：mdqp（Cloudflare Pages + D1）。目标非大而全，只挑低风险高价值项，按里程碑推进。
> 背景：v4.10.1 已上线（来源收集 + 埋点补全 + 设置页来源入口）。本规划聚焦"防误操作"与"管理闭环"。

## 一、后台「查看 / 编辑」权限分离（v4.11 推进 · 低风险高价值）

**现状问题**
- 管理后台默认就是可编辑态：用户列表每行直接挂着「设VIP / 升管 / 删除」按钮，一次误点 = 真实写库。
- 删除类操作虽有 `confirm()`，但无审计、无权限分级，管理员账号本身零防护。
- 与你立的规矩"删除用户数据前必须二次确认"方向一致，但仅靠前端的 `confirm` 不够稳。

**方案（小步、不推翻现有结构）**
1. **默认只读视图**：后台进入即 `adminMode='view'`，所有写按钮（`data-vip/data-role/data-ff/data-deluser`）置灰或隐藏，顶部显示「👁 查看模式」横幅 + 一个「✏️ 进入编辑」按钮。
2. **进入编辑需确认**：点「进入编辑」弹确认框（"你将获得修改权限，操作会被记录"），确认后才切到 `edit` 态、按钮可见。
3. **破坏性操作二次确认 + 审计日志**：删用户 / 撤销 VIP / 改角色 / 删 clip 必须弹专用确认框，明确显示"将把 X 改为 Y / 将删除 Z"，并写入新表 `admin_logs(id, admin_id, action, target_type, target_id, detail, created_at)`。
4. **角色分级（可选、低成本）**：在 `users.role` 之外加 `admin_scope`（view / edit）。`view` 角色只能进查看模式、连「进入编辑」都没有；`edit` 才是当前管理员。

### 本期已完成（v4.11）
- ✅ **`/admin/code` 查看 / 编辑分离**：新增 `edit_code` 权限位（独立于 `view_code`）。仅 `view_code` → 只能浏览源码与审批队列；`edit_code` 或开发者 → 才能编辑并提交改动；开发者仍可一键直部署。`canEdit` 显隐「编辑」按钮，并展示「👁 只读 / ✏️ 可编辑」彩色徽章；权限弹窗中两项用蓝/橙配色区分。

**改动落点（复用现有钩子，不必重写）**
- `public/app.js`：`renderAdminUsers()` 渲染时按 `adminMode` 控制按钮；新增 `enterEditMode()/exitEditMode()`；破坏性 handler 统一走 `confirmDestructive(...)` → 调新接口。
- `src/worker.js`：新增 `POST /api/admin/logs`（写审计）+ `GET /api/admin/logs`（查历史）；破坏性接口内部校验 `admin_scope` 并自动落日志。

## 三、网站优化（用真实数据驱动，别拍脑袋）

- **先攒数据再决定**：`page.view` 已通、`events` 表已建，但真实流量为零（最后 clip 2026-09-07）。先让你/机房同学实跑 1–2 周，再回头看 strategy §八 九个指标，决定 O3–O5 是否值得投。
- **Markdown 编辑器升级**：现有编辑器偏朴素，规划语法高亮、实时预览分栏、拖拽上传图（呼应"多元存储库/图床"方向）、快捷键。
- **首屏与性能**：`vendor` 已本地化；下一步路由级懒加载、列表虚拟滚动（clip 多时）、骨架屏。
- **安全加固**：① 写入接口加真实限流（events 已做 page.view 去重，但 clip/create、VIP 改动仍无限流）；② Markdown 渲染 XSS 防护（确认渲染库已 sanitize）；③ 加 CSP 响应头。
- **移动端/无障碍**：窄屏已支持，补充手势与焦点可达性；老浏览器兼容（P0，等你 UA 实测）。

## 五、错误页与看门狗（v4.11 · 已落地）

- **`/error` 与 `/404` 系统页**：均为 SPA 路由（不加 `/c/` 前缀，与片段区分），内容复用你写的剪贴板文稿（`clip_id=error` / `clip_id=404`），老浏览器也能正常访问。未知路径统一回退到 404 文稿。
- **看门狗自动跳转兼容plus**：`index.html` 兜底脚本新增错误分级——`compat`（兼容性/启动失败等非小错误）直接跳 `/legacy` 兼容备用页；`fatal`（重大渲染错误）跳 `/error`。带防抖与环路保护，已处于 `/legacy`/`/error` 时不重复跳。
