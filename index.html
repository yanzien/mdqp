mdqp

Markdown quickly paste —— 一个把用户数据直接存进 GitHub 的轻量账号系统

这是什么？

本站没有后端、没有数据库。所有用户数据（账号、密码哈希、洛谷账号）都直接以 users.json 的形式保存在本仓库里，任何修改都会通过 GitHub API 实时推送回仓库。

⚠️ 安全性说明：仓库为公开仓库，且 Token 运行在前端，请勿用于真实敏感账号。本项目仅适合练习 / 低敏场景。
